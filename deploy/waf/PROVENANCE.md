# OWASP Core Rule Set

Vendored rules: upstream v4.29.0, commit `ab3ccd5fcd691424ba3f320d4040c61417270193`.
Source: https://github.com/coreruleset/coreruleset/tree/v4.29.0
License: Apache-2.0, preserved in `crs/LICENSE`.

Rules are deployed with the panel release; the OS supplies the ModSecurity Nginx module.
Updating CGPanel installs its bundled rule version. This does not imply continuous
rule downloads, an independent security audit, or upstream volumetric DDoS protection.
