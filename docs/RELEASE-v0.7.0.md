CGPanel 0.7.0 adds a table-based Database Studio, permanent account removal and signed APT distribution, and improves analytics setup.

- Database Studio now has a database/table tree, table search, paginated row browsing, sorting, structure inspection, inserts, edits, deletes and CSV export. Row editing requires a primary key and rejects stale edits. SQL remains available for advanced administration.
- Create tables and add, rename or drop columns. Empty a table while retaining structure, or drop it permanently. Destructive table actions require the exact table name; foreign-key protections remain enabled.
- Database lists and Studio show storage in B, KB, MB, GB, TB and larger units, with exact bytes on hover. MySQL reports table/index estimates; PostgreSQL database totals include overhead.
- Administrators can preview and permanently delete non-admin accounts with typed username confirmation. The panel immediately suspends access, then removes that account's applications, container store, files, volume/recovery copies, databases, mail and local backups in a background job. Foreign ownership/mount conflicts block deletion. Other accounts and external/server-wide backups are preserved. Failed cleanup can be reviewed and retried from Users.
- Analytics now reports tracking configuration and the last received event, and offers opt-in automatic tracker installation on HTML pages served by the domain. Manual, consent-gated installation remains available. Tracking handles application page navigation, clicks and pointer hotspots; duplicate script tags do not duplicate events. Privacy controls remain respected.
- One-line HTTPS bootstrap and a signed Ubuntu 24.04 amd64 APT package/repository. Existing installations migrate through the snapshot/health-check installer. APT-managed panel update actions use APT, keeping package and application versions aligned.

Install and update instructions: [INSTALLATION.md](INSTALLATION.md). Account deletion and Database Studio: [DATABASE-WORKSPACE.md](DATABASE-WORKSPACE.md).

Tests run without a VM: real MariaDB/PostgreSQL operations and isolation; real browser desktop/mobile workflows and telemetry; disposable filesystem/account removal; native Nginx routing/injection; package signature/metadata tests; upgrade/rollback and disk-preflight tests. Systemd, kernel mount/loop and Podman lifecycle checks use adapters where unavailable in containers. Production mail delivery, DNS delegation, server-specific firewall behavior and update downtime depend on the host and cannot be guaranteed by these tests.
